# موکب عشاق الرقیه (س) — وب‌سایت رسمی

وب‌سایت رسمی موکب عُشّاقُ الرُّقَیّه (س)؛ چهار سال پذیرایی به عشق خاندان اهل‌بیت (ع)، زندگینامه‌ها، وقایع ده روز محرم، گالری تصاویر و اطلاعات تماس و موقعیت موکب در نظرآباد.

## فناوری‌ها

- **React 19** و **TypeScript**
- **Vite** برای توسعه و ساخت نسخهٔ استاتیک
- **Tailwind CSS 4** و اجزای رابط کاربری
- **Framer Motion** برای انیمیشن
- فونت **دریا** برای تیترها و **Vazirmatn** برای متن

## پیش‌نیازها

- Node.js نسخهٔ 20.19 یا جدیدتر (یا Node.js نسخهٔ 22.12 یا جدیدتر)
- npm

## اجرا در حالت توسعه

```bash
npm install
npm run dev
```

Vite آدرس محلی را در ترمینال نشان می‌دهد (معمولاً `http://localhost:3000`). اگر پورت 3000 مشغول باشد، Vite به‌طور خودکار پورت آزاد دیگری را انتخاب می‌کند.

## ساخت و پیش‌نمایش نسخهٔ نهایی

```bash
npm run build
npm start
```

خروجی استاتیک در پوشهٔ `dist/` ساخته می‌شود. برای انتشار، محتویات `dist/` را روی هاست استاتیک قرار دهید و مسیرهای سایت را به `index.html` برگردانید.

## ساختار اصلی

```
index.html                 # سند HTML، زبان فارسی و اطلاعات متا
src/main.tsx               # ورودی React
src/styles.css             # سیستم طراحی و استایل‌های سراسری
src/components/site/       # بخش‌های سایت و نمایش جزئیات
src/components/ui/         # اجزای رابط کاربری
src/data/                  # محتوای سایت، زندگینامه‌ها، وقایع و گالری
src/fonts/Darya.ttf        # فونت تیترها
public/images/             # تصاویر سایت و گالری
```

تمام متن‌ها و مسیر تصاویر در فایل‌های `src/data/` متمرکز هستند.

## پیکربندی محتوا

- **آدرس، تلفن، شماره کارت و شبکه‌های اجتماعی:** `src/data/site.ts`
- **زندگینامه‌ها:** `src/data/figures.ts`
- **وقایع محرم:** `src/data/nights.ts`
- **گالری:** `src/data/gallery.ts`
